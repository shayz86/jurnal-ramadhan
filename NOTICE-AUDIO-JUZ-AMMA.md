# Audio Juz Amma — NoorRahma

Juz Amma menggunakan rekaman per-ayat Abdullah Basfar yang dirujuk dari dataset **ashraf-ali/quran-data** di Hugging Face.

Dataset tersebut menyatakan lisensi **CC0 1.0**. Sumber dataset: https://huggingface.co/datasets/ashraf-ali/quran-data

NoorRahma menggunakan URL audio per-ayat dari dataset tersebut dan tidak mengubah rekamannya.

Catatan: lisensi dataset adalah pernyataan dari penerbit dataset. Simpan file ini bersama proyek agar sumber dan dasar lisensi audio terdokumentasi.
